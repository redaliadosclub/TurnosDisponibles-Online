# 🏥 Turnos Disponibles Online - Gestión de Turnos Médicos

Plataforma ágil y moderna para la visualización, reserva y gestión de turnos médicos y especialidades con integración directa a WhatsApp.

🌐 **Sitio Web:** [turnosdisponibles.online](https://turnosdisponibles.online)

---

## ✨ Características Principales

- **Cartelera de Turnos en Tiempo Real:** Búsqueda rápida por especialidad, profesional, fecha y horario.
- **Reserva Directa por WhatsApp:** Notificación y confirmación automatizada con formato de mensaje directo para el paciente y la clínica.
- **Panel Administrativo:**
  - Carga masiva y gestión de turnos disponibles.
  - Gestión de especialidades y profesionales.
  - Estadísticas y control de reservas.
- **Diseño Responsive:** Optimizado para dispositivos móviles, tablets y computadoras de escritorio.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React + TypeScript + Vite
- **Estilos:** Tailwind CSS + Lucide Icons
- **Despliegue & Hosting:** Cloudflare Workers / Pages
- **Dominio:** `turnosdisponibles.online`

---

## 🚀 Despliegue en Cloudflare

Este proyecto está configurado para desplegarse automáticamente mediante GitHub en Cloudflare Workers / Pages usando `wrangler.jsonc`.

- **Comando de compilación:** `npm run build`
- **Directorio de salida:** `./dist`
